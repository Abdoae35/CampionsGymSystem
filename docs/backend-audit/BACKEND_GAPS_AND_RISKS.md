## What is not a gap

The following are deliberate separations in code and should be preserved: a Member profile is not a Sale; PaymentParts/RefundParts are tender evidence, not separate money; a Shift count is an observation, not a cash adjustment; Owner payroll payment records do not invent a drawer funding source; Private expiry settlement creates earning evidence, not attendance; Classes coach statistics do not invent compensation; and periodic expense suggestions do not post paid Expenses. [SalesService](../../CampionsSystem.BLL/Sales/SalesService.cs), [FinancialOperations](../../CampionsSystem.BLL/Shifts/FinancialOperations.cs), [PayrollService](../../CampionsSystem.BLL/MonthlyFinance/PayrollService.cs#L95), [MaintenanceService](../../CampionsSystem.BLL/MonthlyFinance/MaintenanceService.cs#L29).

No source code, migration, database, permission, configuration or pre-existing documentation was changed for these findings. They are audit outputs, not an implementation request.
