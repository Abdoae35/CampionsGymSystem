# Effective permission source

Use the current Owner-only `GET /api/access-administration/permissions` catalog to obtain canonical capabilities and human-readable module titles. `GET /api/auth/me` gives the acting user's effective permissions; Owner inventory endpoints explain role grant, direct Allow/Deny and final effective result. A Deny wins. [Current operation catalog](../API_ENDPOINT_CATALOG.md) lists exact controller policy codes and [access guide](../AUTH_PERMISSIONS_BRANCH_CONTEXT.md) explains additional Owner, branch and actor rules. The earlier static permission inventory in this handoff was superseded because it predated Owner Access Administration, Monthly Closing and Planned Periodic Expenses.
