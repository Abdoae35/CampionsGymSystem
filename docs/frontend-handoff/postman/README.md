# Postman examples
Import `Campions.Auth.postman_collection.json` for existing module and all 36 Coaching route examples. Import `Campeones.V1.Final.postman_collection.json` for 21 current-master examples covering Owner access administration, Shift branch-period review/override, final cancellation and optional InstaPay references, Monthly Finance/Payroll, and Planned Periodic Expenses. The collections complement the full [227-operation catalog](../API_ENDPOINT_CATALOG.md); they are not a claim that every route has a runnable fixture.

Set your own base URL, authorized bearer token, IDs, account methods, dates, current versions and permissions in a private environment. All packaged values are fabricated. **Set a fresh `operationId` for each different mutation; retain the same ID and exact body for an uncertain retry.** Some examples require previously created months, salary/coach targets, Shift or financial accounts. No request was sent to operational customer data in this documentation update. [Integration setup](../INTEGRATION_SETUP_AND_EXAMPLES.md).
