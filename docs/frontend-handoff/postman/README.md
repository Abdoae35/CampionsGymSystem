# Postman examples
Import `Campions.Auth.postman_collection.json`. Set base URL and your own authorized test credentials/token in your private environment. No environment, credentials or real token is packaged. Folder 18 contains 37 examples covering all 36 Coaching routes plus a partial-collection purchase alternative. Its operation variables initialize once, and response scripts capture selected resource IDs/versions. Configure real IDs, dates/start instant and explicitly confirmed target variables before running requests. A retry retains the exact operation ID/body; clear the operation variable only for a different intentional action. Other folders contain existing backend workflow examples. Examples are not operational seed data. [Integration setup](../INTEGRATION_SETUP_AND_EXAMPLES.md).
